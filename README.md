Esta es mi versión de proyecto para consumir la Poke API, se trata de un tetris horizontal, que combina las mecánicas básicas con un minijuego de captura de Pokémons, basado en puntuación. ¡Debes capturar tantos como puedas sin perder la vista del tablero de juego!

Las tecnologías que utilicé fueron React, TailwindCSS y Netlify.
